# 《光的回响》Unity 版

使用 Unity 2022.3.62f3c1 LTS。庭院、森林、地下遗迹和星海由实时三维相机渲染。序幕的森林、地下竖井和星海位于同一个三维场景，人物和萤火会被真实场景几何遮挡。树皮、林地和苔石材质的出处见 [素材说明](../THIRD_PARTY.md)。

1. 在 Unity Hub 里添加本目录。它须与同一个仓库的 `dist` 目录相邻。
2. 首次导入后，选择 `Echoes of Light > Prepare Original Art and Scene` 打开场景并导入素材，再按 Play。
3. 松开空格是张手，按住空格是握拳，Z 模拟轻声，X 模拟较大音量。在森林林道按住 A/B 横移，在迷宫按住 A/B 转向，遗迹按住 A/B 横移。星海用 A/B 放出图案，按住鼠标拖动可以模拟食指。R 重试，Esc 跳过序幕。Play Mode 按 **F1** 或选 **Echoes of Light → Exhibit Controls** 打开独立控制窗。窗内有 A/B、暂停、重试、恢复、章节按钮和游戏设置。控制窗可以拖到操作员屏幕，Game 视图左上角保留文字提示和声音能量。
4. 选择 `Echoes of Light > Build Windows Preview` 构建 Windows x64 正式版，选择 `Build Windows Debug` 构建带 Unity 调试支持的版本。两档输出分别位于 `unity/Builds/Windows/` 和 `unity/Builds/WindowsDebug/`。运行游戏时保留同目录的数据文件。浏览器预览使用 `Build Web Preview`。

### macOS 版

从 [GitHub Releases](https://github.com/huanzro/creative-coding/releases) 下载 `Echoes-of-Light-macOS-Universal.zip`。在 Mac 解压并打开 **Echoes of Light.app**。同一份包支持 Apple 芯片和 Intel 芯片。按 **F1 → 摄像头 / 麦克风** 可启用手势或声音输入，也可用空格、A/B、Z/X 和鼠标进行完整排练。正式演出要连接 Arduino 或使用独立人物投影窗时，请用 Windows 展示版。

给当前 Unity 版本添加 **Mac Build Support (Mono)**，然后选 **Echoes of Light → Build macOS Universal**。在仓库根目录运行下方命令打包并校验应用。

```text
python unity/Tools/PackageMac.py pack "unity/Builds/macOS/Echoes of Light.app" "unity/Builds/Release/Echoes-of-Light-macOS-Universal.zip"
```

## 完整流程

| 场景 | 如何操作 |
| --- | --- |
| 回声庭院 | 握拳约半秒后松开。分别按住 Z 和 X 点亮两盏灯。按 A 看石阶落点，按 B 跨过石阶进入序幕。 |
| 沉睡森林 | 握拳再张手起飞或续跃，发声加快空中前进。用 A/B 在空中或落地时横移。带着黄萤穿过分岔，完成树根迷宫或埋藏的机器，在终点持续出声种光后进入遗迹。 |
| 回声遗迹 | 精灵开局静止。握拳后张手会起跳并向前滑翔，发声可加速。落地后仍可发声前进，安静时会停稳。按住 A/B 自由横移，松手后滑行减速。地面或空中进入左右岔道范围时，按住对应方向即可直接转入。上岔张手进入，下岔下降进入。撞墙后穿门观察隧道框架，再决定是否与机器人交易。 |
| 星海回响 | 精灵持续向星海深处飞，食指引导三维光迹。发声加速，A/B 从光迹两侧长出原创图案。 |

### 星海绘制

1. **长出光纹。** A 在云燕、潮汐、月弧、风羽中随机抽取，B 在交轨、星花、双星涡、弦环中随机抽取。每个图案沿一段弯曲支线从当前笔迹长出来。主画面与独立人物窗共享同一个三维接点和展开进度。
2. **用食指引导光迹。** 从 **F1 → 摄像头 / Arduino** 开启摄像头。把整只手放入画面，只伸出食指，像指着镜头一样移动指尖。精灵会屈肘、转腕、收拢其余手指，绘画端始终落在指尖。手暂时离开画面时，光迹沿当前深度方向续画，指尖回来后接着引导。
3. **调节纵深速度。** 在星海打开 **F1 → 星海飞行 → 巡航速度**。静音时默认每秒前进 0.72，范围为 0.25–1.65。音量增大会加快前进。近处的浮岩、残拱和星尘逐层掠过，序幕里的远岛和星环留在远景。已画下的光固定在三维空间。

自由画的光迹会随机长出小黄花或放出萤火。萤火轻轻飘走后消散，小花留在长出时的三维位置。打开独立人物窗后，投影范围里的光迹和图案由人物窗显示。主画面保留范围外的笔迹、景物和花萤。可用人物窗的 **光效延展** 调整覆盖范围，再打开游戏的 **F1 → 投影校准** 查看边框位置。关掉人物窗即可看到完整光迹。

在 Unity Play Mode 点 **星海** 可单独排练。按住鼠标左键拖动模拟食指，按 Z 或 X 模拟两档声音。停止引导或离开章节时会自动保存。**重试**开一张新画面，**恢复**载入最近保存的笔迹、黄花和当前深度。

星海累计飞行 94.5 米进入尾声，相当于设定上限 3.15 米/秒的 30 秒距离。最后一笔逐渐亮起，画面拉远，完整三维作品收束成金色二维 PNG。按 F1 可调结尾亮度。Windows 会保存 PNG，也会在同一可互通的局域网提供二维码下载。

### 森林飞行与种光

森林起步是一条宽林道。按住 A/B 决定横移距离，松开会滑停在当前位置附近。普通林道落地停止前进，可以继续横移。后段才有通往迷宫和机器门廊的实际分岔。按 **F1 → 森林 · 速度与捕捉范围** 可调整左右移速、迷宫行走速度、蛛网和食人花的捕捉范围，设置保存在本机。

同一区域的 **萤火接触范围** 同时作用于黄萤和红萤。范围为 0.50–2.00 倍，1.00 倍是原设定。

**F1 → 森林调试断点** 可跳到食人花、蜘蛛、迷宫终点、齿轮入口、机器人入口、预测池入口或右路心脏。两类捕获和三个入口从演出的起点播放。迷宫终点和心脏从种光之前开始。按 R 重跑当前断点。点「恢复」读取正常进度。

在 **F1 → 跳跃高度** 可分别调节常规单跳（0.50–2.00 倍，默认 1.00）和森林右路机器门廊的单跳（0.75–4.00 倍，默认 2.60）。门廊的各个入口共用后一组数值。调完后从下一次握拳再张手开始生效。

共同林道的陷阱平时只露出细丝或叶尖。精灵进入陷阱周围的实际半径且在捕捉高度时，蜘蛛或食人花现身并立即抓住精灵。蛛网抓取高处，食人花抓取低处。主画面和独立人物窗会同时显示攻击和吞噬的模型与动作。开局有三只小黄萤，收集增加、碰红萤扣除。随行黄萤和接近的路上萤火会显示在独立人物窗。被食人花抓住时，一只黄萤飞向花瓣缝，逐次撑开下瓣和上瓣。精灵借力挣脱，黄萤在最后一闪时消耗。食人花救援约 6.2 秒。储备归零会触发约 2.5 秒的吞噬，再回到森林入口。种光后的蛛网或食人花演出约 3.7 秒，随后进入遗迹。

- **左路**的林道沿根系和浅水逐渐收拢，接入按本局种子生成的三层实体迷宫。A 向左转，B 向右转，按住可以持续旋转。握拳停步时可以原地调朝向。张手前进，到岔口时进入与当前朝向最接近的隧道。声音（键盘 Z/X）加速。按 **F2** 或画面上的「迷宫地图」查看三层平面和当前朝向。点「指路到出口」即可看到通向根光室的路线。根光室的上下两个光位都要种光。
- **右路**进入巨型机械门廊。三扇入口各有约 13 秒的失败演出，之后回到门前。独立人物窗同步显示夹向精灵的齿轮、递送精灵的机械臂，以及预测池里上升的液面和模仿动作的影像。二楼和一楼入口等高，机房内部在穿过二楼封闭外墙后的暗廊才显露。后段沿机器脊柱滑降至机械心脏，种光会依次唤醒瓣膜、血管和回流脉冲。

到终点光位停稳，张手并持续发声约 0.8 秒。最后一只黄萤可以直接用于完成通关种光。

在迷宫同一层停留满两分钟，青色光标会沿通道指向通往二层或三层的坡道。第三层的光标指向古根空地。跨过坡道抵达新一层后重新计时，暂停期间计时停住。

### 回声遗迹的宝箱与出口

入口碑上写着「find yourself」。九类展厅按首次到访的顺序展开。靠近点亮的托台会自动拾取藏品。第一次接近心脏时，急促的心跳会让精灵缩肩抬手。四类收藏共用 15 个库存格。右上角显示每类数量和单件金币价格。

每层各有一个发光的宝箱，共 16 个。靠近后按 B、右方向键或鼠标右键开盖。设备逐件进入空位，只有容量不足时才出现选择。可以留下设备，或确认放下一个心脏或大脑来换取设备。宝箱的金色光也会显示在独立人物窗。

遗迹以原中央长廊为中心，向周围八区和不同高度展开。每层由长直廊、方向不同的转角和缓坡连接。左右岔道只读取当前按住的方向。可以在进入范围前按住对应方向，精灵抵达时会直接转入。松手后剩下的惯性不会触发岔道。上层入口用向上的灯标和独立提示标出，主廊前段就有一处通往上层的坡道。靠近入口后握拳再张手上升即可进入。下方入口在下降时进入。入口有门时会随进入动作打开。精灵沿弯道延续入岔前的速度，再逐渐调整通行速度。镜头随精灵转入新的实体空间。在 **F1 → 遗迹设置** 中调节前进速度（0.25–1.25 倍，默认 0.55）和四个方向各自的入口范围，设置保存在本机。石灰岩引水廊、靛蓝天文档案、暖铜铸造厅、绿水书库、紫晶镜廊和矿石暗室用不同断面、照明和景物区分。

普通子隧道的实际长度为原来的一半。地图种子决定 6 至 9 次转场后进入最后一条长隧道。最后一条保留原长，到尽头才触发撞墙。玩家停留、观察和拾取时没有倒计时。

在 Unity Play Mode 按 **F1 → 遗迹撞墙断点** 可直接播放撞墙演出。按 **R** 重跑，点「恢复」读取正式存档。断点内的进度不会写入正式存档。

精灵撞墙后，石壁打开，露出悬空的隧道肋架、轨道和分支。进入平台后有 10 秒自由观察。按住 A/B 左右转动视角。对着摄像头张手仰视，发声俯视。键盘调试时按下再松开空格仰视，按 Z 或 X 俯视。观察期间精灵留在平台上。

随后机器人逐件估价。心脏、大脑、手机和电脑分别值 3、4、5、6 枚金币。出口报价等于所带收藏总价减去一件可保留的心脏或大脑的价格。A 同意，B 拒绝。两个分支各播放 10 秒，从遗迹穿过森林，再进入星海。F1 设置可切换中英文界面和配音。

Unity Play Mode 中按 **F1 → 打开独立人物窗口**，也可以用编辑器顶部的 **Echoes of Light → Character Projection**。把浮动窗口标题栏拖到第二块屏幕。**人物大小**（35%–140%，受窗口边缘约束）与**光效延展**（0.65–2.45 倍）可以分别调，设置保存在本机。人物窗的 **M** 切换镜像、**R** 切换横放和直立、**H** 隐藏控制条。关掉人物窗会让精灵回到 Game 视图。两个窗口读取同一个姿态和飞行路径，主画面保留较淡的光迹与光圈。

进入关卡后打开 **F1 → 投影校准**。全屏亮度曲线调节三维主画面的整体明暗（系数 0.50–1.35，默认 1.00），提亮时保留高光细节。渐亮速率范围为 0.25–4.00 倍。最低档将角色背后的背景压到纯黑，再向四周平滑恢复亮度。倍率越大，暗区收得越紧。单屏和双屏的三维主画面都实时显示渐亮。单屏会保留角色轮廓，人物窗保持黑底。设置自动保存在本机。

**背景亮度**只调整主画面的环境，降到 0.00 倍时环境变黑。**蜘蛛动画亮度**和**食人花动画亮度**分别调整主画面里的捕捉、救援和吞噬演出，降到 0.00 倍时隐藏对应演出。三项均可在 0.00–1.35 倍间调节，默认 1.00 倍。独立人物窗始终使用自己的显示设置。

同一面板里的 **主画面大小** 可在 50%–100% 之间实时等比缩放。游戏画面居中，关闭设置后四周留纯黑边。校准面板打开时保持可读大小，人物投影窗口可用自己的「人物大小」控件调整。

**F1 → 出场角色**可选三维精灵、绿金长裙精灵、兜帽旅人、星纹术士、红色小鸟和黑天鹅。六个角色共用动作时序和落脚基准，鸟类用翼尖完成触碰、种光和星海描画。选择会保存在本机，并同步用于游戏、序幕和人物窗。**F1 → 预览片头**会播放带片名的完整序幕。

森林与遗迹中，握拳再张手会发出光圈并上升。保持较大音量，握拳蓄力后张手，角色会随光圈转一整圈，再恢复背向滑翔。键盘可同时按住 X 和空格约半秒，继续按住 X 并松开空格。星海中，音量控制巡航加速。

Windows Unity Play Mode 和 Windows 试玩都可从 **F1 → 摄像头 / Arduino → 开启摄像头** 启动手势识别。在本机识别页允许摄像头后切回 Unity，并保持识别页打开。识别页上的 **打开独立预览** 会打开带镜像取景框、食指亮点和实时手势状态的小窗口。MediaPipe 优先在浏览器的后台线程识别最新的画面，通过本机连接发送手势和食指坐标。短时请求失败、摄像头断流或画面停滞后会尝试自动恢复。Unity 会暂停依赖手势的前进，森林和遗迹仍可用 A/B 横移或转向。在同一设置页可开启麦克风。首次使用时安静 2 秒，接着舒适地哼声 3 秒，之后会复用本机校准。

在 **F1 → 摄像头 / Arduino** 可从 Windows 检测到的端口中选 Arduino，再点「连接 Arduino」。重插 USB 后可点「刷新端口」。如果端口被占用，先关闭 Arduino IDE 串口监视器或其他占用程序。如果端口已打开却收不到 EOL3，检查是否已烧录项目的展台固件。设备页会显示 A/B 的按住状态和按下、松开次数。A/B 输入和双灯、风扇共用一个 EOL3 串口。双灯和风扇各有启用开关，组合固件报告支持后才可启用风扇。Game、独立控制窗和人物窗之间切换时，触觉按住状态会跟随 Arduino 最新报告。暂停、切到其他应用、停止 Play Mode 或串口失联时会取消输出。接线与烧录见 [EOL3 展台说明](../docs/EXHIBIT_WIRING.md)。

WebGL 导出支持摄像头和麦克风权限，按设备复用校准。导出版可用浏览器的双屏投影按钮打开人物窗，拖到第二块屏后双击全屏。D 盘编辑器里的独立窗口用于本机调试，双实体屏的摆位和投影仍需现场验证。
