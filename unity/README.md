# 《光的回响》Unity 版

使用 Unity 2022.3.62f3c1 LTS。庭院、森林、地下遗迹和星海由实时三维相机渲染。序幕的森林、地下竖井和星海位于同一个三维场景，人物和萤火会被真实场景几何遮挡。树皮、林地和苔石材质的出处见 [素材说明](../THIRD_PARTY.md)。

1. 在 Unity Hub 里添加本目录。它须与同一个仓库的 `dist` 目录相邻。
2. 首次导入后，选择 `Echoes of Light > Prepare Original Art and Scene` 打开场景并导入素材，再按 Play。
3. 松开空格是张手，按住空格是握拳，Z 模拟轻声，X 模拟较大音量。在森林和遗迹按 A 向左、B 向右。庭院和星海使用各自的 A/B 提示。R 重试，**恢复**读取最近的有效进度。底部四个章节按钮供单独排练。Esc 可以跳过序幕。
4. 选择 `Echoes of Light > Build Windows Preview` 可构建 Windows x64 试玩，运行 `unity/Builds/Windows/Echoes of Light.exe` 时保留同目录的数据文件。浏览器预览使用 `Build Web Preview`，输出在 `unity/Builds/Web/`。

## 完整流程

| 场景 | 如何操作 |
| --- | --- |
| 回声庭院 | 握拳约半秒后松开。分别按住 Z 和 X 点亮两盏灯。按 A 看石阶落点，按 B 跨过石阶进入序幕。 |
| 沉睡森林 | 握拳再张手起飞或续跃，发声加快空中前进。用 A/B 在空中或落地时横移。带着黄萤穿过分岔，完成树根迷宫或埋藏的机器，在终点持续出声种光后进入遗迹。 |
| 回声遗迹 | 背对镜头纵深前进，用 A/B 和飞行高度选择洞口。掌印门握拳约半秒再张手，共鸣门张手并轻声约半秒。探索不同子隧道，撞墙后选择系统引导或带着记忆重试。 |
| 星海回响 | 握拳、张手起飞至暖光高度，或看过建议后按 B 授权一段。执行中再按 B 可收回。三段完成时握拳半秒再张手，留下一颗自己的星。 |

手部信号丢失时，关卡节拍会等待手重新张开。星图记录走过的遗迹支路、接过的授权、撤回和修正。音量用于速度和信号窗口。

### 森林飞行与种光

精灵背对镜头滑翔。A/B 横移约一秒，反向时先减速再转向。普通林道落地停止前进，可以继续横移。开局有三只随行黄萤，收集增加一只，碰红萤扣一只。随行小黄萤绕在人物周围，路上的两色萤火靠近时也会出现在独立人物窗。

共同林道前段从中层也能看见树冠蜘蛛和低处食人花。真正的捕获设在高、低两层。被困时一只黄萤会离开队伍，尝试救援并消散，精灵脱困落稳后继续。储备归零会坠落并回到森林入口。

- **左路**是按本局种子生成的三层实体迷宫。轻声（键盘 Z）前进，停声停步，岔口短按 A/B，长按任一触点约 0.72 秒可以掉头。走进死路后会停一秒、转身、沿走过的通道回到最近的岔口，再面向岔路。最快路线也需要走至少一分钟。终点上下两处都要种光。
- **右路**进入巨型机械门廊。三扇入口各有约 13 秒的失败演出，结束后回到门前，恢复进门时的黄萤数量。机房内的路径和声音随探索展开。

到终点光位停稳，张手并持续发声约 0.8 秒。最后一只黄萤可以直接用于完成通关种光。

### 回声遗迹的宝箱与重试协议

入口碑上写着「find yourself」。漂浮的文明模型是 AI 档案的展品。可收集的心脏、大脑、手机和电脑藏在墙缘、地表或拱顶的小片余光里。靠近才逐步看清形体。第一次接近心脏，急促的心跳会让精灵缩肩抬手。后续心脏仍会跳动。四类收藏共用 15 件上限，宝箱另外计入发现记录。

每箱有 2–4 件手机或电脑，开盖时逐件升起。用 A 切换选项，B 确认。设备入包即锁定。容量不足时可以确认放下一个心脏或大脑来交换，也可以把未选设备留在箱中，折返再取。箱内库存、已打开的门和已取得的收藏会写入存档。

不同洞口从宽处就能看出轮廓。侧口要用 A/B 靠边。拱顶入口可以连续握拳、张手爬升，低处入口可沿地面靠近。靠近有门的入口时能看到对应动作提示。开门后改变路线可以继续走原来的隧道。上层穹顶、下层书库和藏室以灯光、结构和空间大小区分，进洞后仍有后续分支。

每轮首次探索 6–9 个不同子隧道后，白光会在一段宽阔隧道收拢成墙。墙内回放真实的分岔或一次腾位取舍。选 A 让系统沿蓝线带一段，暖光出现时可按 B 接管。选 B 跟着上次的暖色轨迹选方向，再安静听完两拍，张手轻声开门。在墙边按 R 会回到选择点。通关按 A 或 B 去星海，结尾星图会留下引导、接管或亲自重试的痕迹。

Unity Play Mode 中按 **F1 → 打开独立人物窗口**，也可以用编辑器顶部的 **Echoes of Light → Character Projection**。把浮动窗口标题栏拖到第二块屏幕。**人物大小**（35%–140%，受窗口边缘约束）与**光效延展**（0.65–2.45 倍）可以分别调，设置保存在本机。人物窗的 **M** 切换镜像、**R** 切换横放和直立、**H** 隐藏控制条。关掉人物窗会让精灵回到 Game 视图。两个窗口读取同一个姿态和飞行路径，主画面保留较淡的光迹与光圈。

**F1 → 出场角色**保留原三维精灵和绿金长裙精灵，并加入兜帽旅人、星纹术士。选择会保存在本机，并同步用于游戏、序幕和人物窗。**F1 → 预览片头**从头播放 37.6 秒序幕。

握拳再张手会发出光圈，精灵随光上升，展开双臂后缓慢滑翔。按住 **空格＋X** 蓄力约半秒，再保持 X、松开空格会增强滑翔光迹，星海的高速释放会转身。森林与遗迹保持背向飞行。森林的换道、种光、蛛网捕获和花瓣合拢有各自的动作。

在 Unity 游戏设置中可开启原生麦克风。首次使用时安静 2 秒，接着舒适地哼声 3 秒。本机保存该麦克风的校准，重新开启时复用。真实手势识别仍走浏览器，Unity Play Mode 内用空格和“模拟手离开”覆盖相同的输入状态。

Windows 的 Unity 游戏设置可填写设备管理器里的 COM 号并连接 Arduino。A/B 输入和双灯、风扇共用一个 EOL3 串口。森林收集黄萤时灯 A 微亮暖黄，撞到红萤时灯 B 微亮红色。双灯和风扇各有启用开关，组合固件报告支持后才可启用风扇。暂停、失去窗口焦点、停止 Play Mode 或串口失联会取消输出。接线与烧录见 [EOL3 展台说明](../docs/EXHIBIT_WIRING.md)。

WebGL 导出支持摄像头和麦克风权限，按设备复用校准。导出版可用浏览器的双屏投影按钮打开人物窗，拖到第二块屏后双击全屏。D 盘编辑器里的独立窗口用于本机调试，双实体屏的摆位和投影仍需现场验证。
