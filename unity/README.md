# 《光的回响》Unity 版

使用 Unity 2022.3.62f3c1 LTS。庭院、森林、地下遗迹和星海由实时三维相机渲染。序幕的森林、地下竖井和星海位于同一个三维场景，人物和萤火会被真实场景几何遮挡。树皮、林地和苔石材质的出处见 [素材说明](../THIRD_PARTY.md)。

1. 在 Unity Hub 里添加本目录。它须与同一个仓库的 `dist` 目录相邻。
2. 首次导入后，选择 `Echoes of Light > Prepare Original Art and Scene` 打开场景并导入素材，再按 Play。
3. 松开空格是张手，按住空格是握拳，Z 模拟轻声，X 模拟较大音量。在森林林道按住 A/B 横移，在迷宫按住 A/B 转向，遗迹按住 A/B 横移。庭院和星海使用各自的 A/B 提示。R 重试，**恢复**读取最近的有效进度。底部四个章节按钮供单独排练。Esc 可以跳过序幕。
4. 选择 `Echoes of Light > Build Windows Preview` 可构建 Windows x64 试玩，运行 `unity/Builds/Windows/Echoes of Light.exe` 时保留同目录的数据文件。浏览器预览使用 `Build Web Preview`，输出在 `unity/Builds/Web/`。

## 完整流程

| 场景 | 如何操作 |
| --- | --- |
| 回声庭院 | 握拳约半秒后松开。分别按住 Z 和 X 点亮两盏灯。按 A 看石阶落点，按 B 跨过石阶进入序幕。 |
| 沉睡森林 | 握拳再张手起飞或续跃，发声加快空中前进。用 A/B 在空中或落地时横移。带着黄萤穿过分岔，完成树根迷宫或埋藏的机器，在终点持续出声种光后进入遗迹。 |
| 回声遗迹 | 精灵开局静止。轻声慢行，较大音量加快，停声停稳。按住 A/B 自由横移，松手后滑行减速。进入左右岔道范围时，当前移动方向决定是否直接转入。上岔张手进入，下岔下降进入。撞墙后选择系统引导或带着记忆重试。 |
| 星海回响 | 握拳、张手起飞至暖光高度，或看过建议后按 B 授权一段。执行中再按 B 可收回。三段完成时握拳半秒再张手，留下一颗自己的星。 |

手部信号丢失时，关卡节拍会等待手重新张开。星图记录走过的遗迹支路、接过的授权、撤回和修正。音量用于速度和信号窗口。

### 森林飞行与种光

森林起步是一条宽林道。按住 A/B 决定横移距离，松开会滑停在当前位置附近。普通林道落地停止前进，可以继续横移。后段才有通往迷宫和机器门廊的实际分岔。按 **F1 → 森林 · 速度与捕捉范围** 可调整左右移速、迷宫行走速度、蛛网和食人花的捕捉范围，设置保存在本机。

共同林道的陷阱平时只露出细丝或叶尖。精灵进入陷阱周围的实际半径且在捕捉高度时，蜘蛛或食人花现身并立即抓住精灵。蛛网抓取高处，食人花抓取低处。主画面和独立人物窗会同时显示攻击和吞噬的模型与动作。开局有三只小黄萤，收集增加、碰红萤扣除。随行黄萤和接近的路上萤火会显示在独立人物窗。被困时一只黄萤会离队救援并消散，精灵脱困落稳后继续。储备归零会坠落并回到森林入口。

- **左路**的林道沿根系和浅水逐渐收拢，接入按本局种子生成的三层实体迷宫。A 向左转，B 向右转，按住可以持续旋转。握拳停步时可以原地调朝向。张手前进，到岔口时进入与当前朝向最接近的隧道。声音（键盘 Z/X）加速。按 **F2** 或画面上的「迷宫地图」查看三层平面和当前朝向。点「指路到出口」即可看到通向根光室的路线。根光室的上下两个光位都要种光。
- **右路**进入巨型机械门廊。三扇入口各有约 13 秒的失败演出，之后回到门前。二楼和一楼入口等高，机房内部在穿过二楼封闭外墙后的暗廊才显露。后段沿机器脊柱滑降至机械心脏，种光会依次唤醒瓣膜、血管和回流脉冲。

到终点光位停稳，张手并持续发声约 0.8 秒。最后一只黄萤可以直接用于完成通关种光。

### 回声遗迹的宝箱与重试协议

入口碑上写着「find yourself」。遗迹九类展厅按首次到访新隧道的顺序展开，依次是物理、数学、工业、建筑、文学、计算机、教育、医学和心理学。回访沿用原来的主题。文明成果以悬浮模型陈列，靠近可阅读展签。16 个空间各有 7 件藏品，两侧都设有亮灯的暗龛，共 112 件。首层就能找到心脏、大脑、手机和电脑。沿地面灯标靠近暗龛，藏品会在托台上逐渐显露。停声看清之后按 B 拾取。第一次从侧面接近心脏，急促的心跳会让精灵缩肩抬手。后续心脏仍会跳动。四类收藏共用 15 件上限，宝箱另外计入发现记录。

靠近宝箱并停下，按 B 开盖。每箱有 2–4 件手机或电脑，开盖时逐件升起。用 A 切换选项，B 确认。设备入包即锁定。容量不足时可以确认放下一个心脏或大脑来交换，也可以把未选设备留在箱中，折返再取。箱内库存、已打开的门和已取得的收藏会写入存档。

遗迹以原中央长廊为中心，向周围八区和不同高度展开。每层由长直廊、方向不同的转角和缓坡连接。左右岔道只读取当前按住的方向。可以在进入范围前按住对应方向，精灵抵达时会直接转入。松手后剩下的惯性不会触发岔道。上方入口用张手，下方入口在下降时进入。入口有门时会随进入动作打开。精灵沿弯道延续入岔前的速度，再逐渐调整通行速度。镜头随精灵转入新的实体空间。按 **F1 → 遗迹入口范围** 可以分别调节左、右、上、下的触发范围，设置保存在本机。石灰岩引水廊、靛蓝天文档案、暖铜铸造厅、绿水书库、紫晶镜廊和矿石暗室用不同断面、照明和景物区分。

沿岔道探索时，九类展厅都呈现后，白光会在一段宽阔隧道收拢成墙。始终留在初始长廊时，走完一圈也可触发白墙。玩家停留、观察和拾取时没有倒计时。墙内回放真实的分岔或一次腾位取舍。选 A 让系统沿蓝线带一段，暖光出现时可按 B 接管。选 B 跟着上次的暖色轨迹选方向，再安静听完两拍，张手轻声开门。在墙边按 R 会回到选择点。通关按 A 或 B 去星海，结尾星图会留下引导、接管或亲自重试的痕迹。

Unity Play Mode 中按 **F1 → 打开独立人物窗口**，也可以用编辑器顶部的 **Echoes of Light → Character Projection**。把浮动窗口标题栏拖到第二块屏幕。**人物大小**（35%–140%，受窗口边缘约束）与**光效延展**（0.65–2.45 倍）可以分别调，设置保存在本机。人物窗的 **M** 切换镜像、**R** 切换横放和直立、**H** 隐藏控制条。关掉人物窗会让精灵回到 Game 视图。两个窗口读取同一个姿态和飞行路径，主画面保留较淡的光迹与光圈。

进入关卡后打开 **F1 → 投影校准**。全屏亮度曲线调节三维主画面的整体明暗（系数 0.50–1.35，默认 1.00），提亮时保留高光细节。渐亮速率范围为 0.25–4.00 倍。最低档将角色背后的背景压到纯黑，再向四周平滑恢复亮度。倍率越大，暗区收得越紧。单屏和双屏的三维主画面都实时显示渐亮。单屏会保留角色轮廓，人物窗保持黑底。设置自动保存在本机。

**F1 → 出场角色**保留原三维精灵和绿金长裙精灵，并加入兜帽旅人、星纹术士。选择会保存在本机，并同步用于游戏、序幕和人物窗。**F1 → 预览片头**从头播放 37.6 秒序幕。

握拳再张手会发出光圈，精灵随光上升，展开双臂后缓慢滑翔。按住 **空格＋X** 蓄力约半秒，再保持 X、松开空格会增强滑翔光迹，星海的高速释放会转身。森林与遗迹保持背向飞行。森林的换道、种光、蛛网捕获和花瓣合拢有各自的动作。

Windows Unity Play Mode 和 Windows 试玩都可从 **F1 → 摄像头 / Arduino → 开启摄像头** 启动手势识别。在弹出的本机识别页允许摄像头，看到「Unity 已收到：张手」后切回 Unity，保持识别页打开。进入试玩或关卡后，先张手，握拳约半秒，再张手触发光圈和起飞。Edge 和 Chrome 的识别页在后台也能读取摄像头画面。MediaPipe 在本机浏览器处理视频，游戏通过本机连接接收张手、握拳和无手三种状态。关闭摄像头后可使用键盘模拟。在同一设置页可开启麦克风。首次使用时安静 2 秒，接着舒适地哼声 3 秒，之后会复用本机校准。

在 **F1 → 摄像头 / Arduino** 可从 Windows 检测到的端口中选 Arduino，再点「连接 Arduino」。重插 USB 后可点「刷新端口」。如果端口被占用，先关闭 Arduino IDE 串口监视器或其他占用程序。如果端口已打开却收不到 EOL3，检查是否已烧录项目的展台固件。A/B 输入和双灯、风扇共用一个 EOL3 串口。双灯和风扇各有启用开关，组合固件报告支持后才可启用风扇。暂停、失去焦点、停止 Play Mode 或串口失联时会取消输出。接线与烧录见 [EOL3 展台说明](../docs/EXHIBIT_WIRING.md)。

WebGL 导出支持摄像头和麦克风权限，按设备复用校准。导出版可用浏览器的双屏投影按钮打开人物窗，拖到第二块屏后双击全屏。D 盘编辑器里的独立窗口用于本机调试，双实体屏的摆位和投影仍需现场验证。
