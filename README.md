# Creative Coding — 光的回响

基于最新原型的双屏投影版本。背景和角色分别显示在同一电脑的两个窗口中。v0.4 加入音量控制移动速度、增强光迹，以及风扇 / WS2812B 彩灯接口。

## 启动

需要 Python 3。在项目目录运行：

```sh
python server.py --open
```

点击“开启双屏投影”，允许弹窗，并把人物窗口拖到第二块屏幕。双击全屏，H 隐藏提示，M 镜像。保持主窗口可见。

## 声音、手势与实体反馈

- **声音**：点击“开启麦克风”，再安静两秒校准；轻声慢，大声快，静音逐渐停下。只检测音量，不检测音调。
- **手势**：保留张开 → 握拳的跃起与能力触发；可与声音同时使用。选择手势后摄像头未就绪 / 丢手仍会暂停。
- **光迹**：柔光、彩色光带、细亮芯与微粒；随声音能量增强，同时出现在纯黑人物投影窗口。
- **调试**：展开“声音与光迹调试”，调整阈值、最高速度、平滑及光迹强度；可用模拟滑块先测试，不需要麦克风。
- **风与灯**：默认仅预览。提供 Web Serial 连接、独立启用开关、上限、停止按钮及 UNO 接收示例。模拟模式不驱动实体设备。

详细说明：[音量与光迹调试](docs/VOLUME_TUNING.md) · [风扇与彩灯协议 / 接线方向](docs/HARDWARE.md) · [UNO 接收示例](hardware/echoes_uno/echoes_uno.ino)

## 测试

安装 Node.js 后运行 `node --test tests/*.test.js`，或 `npm test`。无第三方依赖的 23 项自动测试覆盖原玩法、音量响应和串口输出逻辑。

可选浏览器检查：已安装桌面 Edge 和 `playwright` 包时运行 `node tests/browser-smoke.cjs`。该脚本在独立无头 Edge 中用本地文件路由与合成音频测试，不访问真实麦克风 / 账号，截图写到忽略上传的 `test-output/`。它不测试 Python 服务器网络连接。
