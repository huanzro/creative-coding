# Creative Coding · 光的回响

当前开发与调试入口为 [Unity 工程](unity/README.md)。以下启动命令对应此前发布的网页版，可用于核对体验与硬件协议。

同一位小精灵穿过森林、遗迹和星海。握拳收束，张手展开，呼吸般的声音改变世界如何回应。人物保持在画面中央，由背景、目标和光迹表现行进。

## 启动与输入

使用 Python 3 启动，再用桌面 Edge 或 Chrome 打开终端显示的本机地址。

```sh
python server.py --open
```

1. 开启摄像头，把手放入画面，先完整张开。若张手和握拳难以稳定区分，可重新校准手势。
2. 首次使用这支麦克风时，安静 2 秒，再舒适地哼声 3 秒。声音越强，背景与光迹移动越快。已完成的设置保存在当前浏览器，重新打开时自动沿用。
3. 触摸画面下方 A/B，或用 Arduino 的两块实体触摸区。庭院和森林中，A 选林荫绕路，B 选风带捷径。星海中，A 选同相，B 选反相。遗迹中，两块触摸区均可开始记录或合作。空格仍可切换当前选项或代替一次点击。

「回声庭院」会用三个小试验教会张手、握拳、声音和点击。通过后进入森林，选择长而稳的林荫路，或握拳护光穿过风带。遗迹先记录自己的动作，再与回声做相反的动作。星海则用同相或反相回应来波，最后由世界接住玩家发出的三道波。页面顶部的「游戏设置」可选章节、时段和滚动速度，也可重试或继续上次旅程。

旅程启动后，手移出镜头时继续计时，直到设备真正断开或手动暂停。把手放回镜头时先张手，再继续握拳。

## 投影与展台

点击「开启双屏投影」，把人物窗口拖到第二块屏幕。双击全屏，H 隐藏人物窗口提示，M 左右镜像。把主窗口和人物窗口都保持可见。「游戏设置」中的「纯黑人物展示」可单独查看角色，切回后继续同一段旅程。

- [麦克风校准与音量反馈](docs/VOLUME_TUNING.md)
- [风扇接线与旧 EOL2 接口](docs/HARDWARE.md)
- [EOL3 组合固件与展台接线](docs/EXHIBIT_WIRING.md)
- 在「展台硬件」连接 Arduino 一次。启用实体灯光后，A/B 分别点亮暖灯和蓝灯。「灯光跟随场景」与「启用风扇输出」各自可开关。要使用风扇，需上传支持该通道的组合固件。独立调试页可测试舵机，打开前先断开游戏串口。

## 验证与部署

运行 `node --test "tests/*.test.js"`（或 `npm test`）验证状态机、手势门控、声音校准、旧资源和串口协议。可选浏览器检查用 `node tests/browser-smoke.cjs`，需要 Playwright 和桌面 Edge。先启动 `python server.py --port 8776`，用 `ECHOES_BROWSER_TEST_ORIGIN` 可指定另一个本机或 HTTPS 地址。

`dist/` 可在本机运行或部署到支持 HTTPS 的静态网站托管。三个历史章节的 `chapter1-offline.html` 至 `chapter3-offline.html` 路径仍可访问。素材来源见 [THIRD_PARTY.md](THIRD_PARTY.md)，真人和自动验证的区分见 [VERIFICATION.md](VERIFICATION.md)。
