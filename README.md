# Creative Coding — 光的回响

基于最新原型的双屏投影版本。背景和角色分别显示在同一电脑的两个窗口中。

## 启动

需要 Python 3。在项目目录运行：

```sh
python server.py --open
```

点击“开启双屏投影”，允许弹窗，并把人物窗口拖到第二块屏幕。双击全屏，H 隐藏提示，M 镜像。保持主窗口可见。

## 测试

安装 Node.js 后运行 `npm test`。

## 协作

每项修改新建分支，完成后提交 Pull Request，请组员检查后合并。不要提交密码、令牌或个人摄像头录像。
