# 《把光种进森林》展台接线

按「project (4.1)」最新材料清单准备 UNO R3、两串标有 5V / DIN / GND 的灯、一只微型舵机、一到两只稳定触摸模块和一块自制导电布。这轮先测试每路硬件，为“按住 → 发声 → 松手 → 开花”保留输入和输出。

| 材料 | UNO 信号脚 | 供电与接线 |
|---|---|---|
| 稳定触摸 A | D2 | 已确认支持 5V 的数字模块，VCC 接 UNO 5V，GND 接 UNO GND，OUT 接 D2。两脚开关则一端接 D2，另一端接 GND。 |
| 稳定触摸 B | D3 | 接法同 A。展台固件默认启用，默认低电平有效。 |
| 导电布 | D4 | 两片导电布分别接 D4、GND，中间夹开孔的绝缘布。按住时两片接触，松手时分离。 |
| 微型舵机 | D5 | SIG 接 D5，电源正极接符合铭牌的独立低压电源，负极接公共 GND。按铭牌、插头定义或数据手册确认三个针脚。 |
| 灯 A（触摸区） | D6 | D6 → 330–470 Ω → 第一颗灯的 DIN。灯的 5V 接外置稳压 5V，GND 接公共 GND。 |
| 灯 B（实体花） | D7 | D7 → 独立的 330–470 Ω → 第一颗灯的 DIN。电源与 A 并联。 |
| Arduino UNO R3 | USB | 数据线接电脑，实现串口通信并给 UNO 自己供电。 |

## 电源怎么分

```text
电脑 ── USB 数据线 ── UNO
UNO D6 ── 330~470 Ω ── 灯 A DIN
UNO D7 ── 330~470 Ω ── 灯 B DIN
UNO D5 ─────────────── 舵机 SIG

外置稳压 5V 正极 ──┬── 灯 A 5V
                   ├── 灯 B 5V
                   └── 舵机 V+（仅当铭牌允许 5V）
电源负极 ──────────┬── 灯 A / B GND
                   ├── 舵机 GND
                   └── UNO GND
```

如果舵机需要不同电压，用它自己的电源，两个电源负极和 UNO GND 连在一起，正极各走各的。UNO 已通过 USB 供电，外置电源正极只接负载。把灯和舵机的回流线直接接到外置电源负极，避免大电流经过 UNO 或细杜邦线。断电接线，电源入口可并接 500–1000 µF、耐压至少 6.3 V 的电解电容。电容有正负极。

灯条确认型号后按规格估算电流。常见传统 RGB NeoPixel 可按每颗满白 60 mA 做上限估算。例如总计 30 颗，灯条约 1.8 A，再加舵机规格上的堵转电流并留余量。先数出每串灯珠，再选电源，不按本例的颗数购买。[NeoPixel 供电与接线](https://learn.adafruit.com/adafruit-neopixel-uberguide/powering-neopixels) · [Arduino 舵机供电](https://docs.arduino.cc/learn/electronics/servo-motors/)

## 接线前确认这三样

1. **灯条芯片和灯数**。当前固件按两串各 15 颗、800 kHz GRB 配置。换灯条时，根据芯片规格、色序和颗数调整 `PIXELS_A`、`PIXELS_B` 及驱动配置。按灯板上的箭头确认 DIN 端。
2. **稳定触摸模块针脚、供电和触发电平**。三脚模块先查丝印和产品说明，只接已确认的 VCC、GND、数字 OUT。低有效的开关或兼容 5V 上拉的开漏输出可用默认配置。按下输出 HIGH 的推挽模块，把对应 `activeHigh` 改为 `true`。三脚模块若只有模拟输出或额定电压不明，先确认型号。用瞬时模式，按住和松开要能分开读出来。
3. **舵机型号和限位**。首次卸下连杆，命令 90° 后装舵臂，再试 75° 和 105°。根据实际花瓣机构校准行程。释放信号后舵机可能失去保持力，花瓣靠机械设计停在安全位置。

自制布开关先用万用表确认松开断路、按下导通，再接 D4 与 GND。导电布这路无需单独接 5V。固件消除短时抖动，后续网页可在一次体验里只接受一次布料事件，再抽选颜色或花形。[Arduino 内部上拉接法](https://docs.arduino.cc/built-in-examples/digital/InputPullupSerial/)

## 先测哪一路

1. Arduino IDE 选择 **Arduino Uno**，在库管理器安装 **Servo** 和 **Adafruit NeoPixel**。打开 `hardware/echoes_exhibit_uno/echoes_exhibit_uno.ino`，核对顶部常量和输入配置后编译、上传。这是一份独立固件，测试这一版时使用 EOL3 调试页。
2. 保持灯和舵机暂不接电，关闭 Arduino IDE 串口监视器，在桌面 Edge／Chrome 打开[展台硬件调试](https://echoes-of-light-interactive-1031.tanbowl.chatgpt.site/exhibit-hardware.html)。点「连接 Arduino」并选 UNO 端口。显示 EOL3 已连接后，逐个按下、松开，检查 D2、D3、D4。
3. 只接灯 A，舵机选择「释放」，勾选「启用实体输出」，选 10% 或更低的亮度并发送。测试 B 时可以把 A 的颜色设为黑色。回执证明 Arduino 收到了命令，用眼睛确认每串灯实际亮起。
4. 再接舵机供电并试 90°。确认正常后再测试小幅度行程，最后安装花瓣。停止按钮、离开页面或 800 ms 内没有有效输出包时，固件熄灯并释放舵机。

## 留给创作代码的接口

游戏中启用「实体灯光」后，A 联动暖灯，B 联动蓝灯，松手后渐熄。网页 A/B 与实体触摸使用同一套选择规则。暂停、离开页面或断连会停止游戏灯光。舵机保留在 EOL3 中，游戏发送 `servo: null`，需要测试角度时先断开游戏串口，再使用独立调试页。

`dist/exhibit-serial.js` 中的 `ExhibitSerial` 管理 USB 串口。正式游戏可复用这一类，在页面按钮触发的操作里连接，并由同一个页面拥有串口。一个 COM 口只能被一个页面或程序占用。

| 接口 | 用途 |
|---|---|
| `inputs` 事件 | 当前三路输入状态，未启用的通道为 `null` |
| `touch` 事件 | `{source, pressed}`，区分按住开始和松开，可接到“种花”流程 |
| `setArmed(true)` | 操作者明确开启实体输出后才调用 |
| `setOutputs({lampA, lampB, servo})` | 两组三通道 RGB 和舵机角度。测试版颜色各通道 0–64，角度限制 60°–120°，`null` 释放。 |
| `setArmed(false)` | 发送熄灯和释放请求 |
| `ack` 事件 | 收到命令序号，用于对照串口通信 |

波特率 115200，每行以换行结束。Arduino 输入包 `EOL3 IN <按下位掩码> <启用位掩码>`，位序从低到高为 A、B、布料。网页输出 `EOL3 SET <seq> <Ar Ag Ab> <Br Bg Bb> <angle>`，`-1` 释放，固件回复 `EOL3 ACK <seq>`。具体的游戏映射可以后接。麦克风和摄像头继续接电脑。
