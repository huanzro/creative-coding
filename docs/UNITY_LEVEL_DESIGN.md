# 《光的回响》关卡与角色演出

## 纵深森林之后的关卡方向

试玩之后，森林已采用统一操作。A 向左、B 向右，每触一次换一条路线。握拳再张手起飞，声音调节空中速度。遗迹和星海可以沿用这套操作，让环境教会玩家两个章节的新规则。下面是可继续制作的关卡提案。

### 第二关 · 回声遗迹

1. **让错一拍的影子帮忙。** 左右两排石板会记录你飞过的节拍，蓝色残影下一轮会逐拍重放。窄门两边各需一只手同时够到，玩家要提前一轮把残影留在左边，自己从右边补上。玩家可先在宽阔水面试出第一次回放，再挑战必须重叠半拍的窄门。重试从门前最近一块亮石板开始。
2. **三种证据拼出误判。** 地板压痕保留真实路线，石墙浮雕显示系统判断，手掌里的回声可以重播一次。玩家先看开关，飞到自己确认的正确一侧，轻声点亮证据。连续两扇门制造不同矛盾。前一扇的路线判断错了，后一扇的时机判断错了。背景显示证据差异，人物窗只显示手心回放和观察动作。
3. **让安静浮出暗桥。** 发声时石轮沿轨道转动，停下发声时，余响会逐段显出被遮住的桥。玩家需要用短促加速赶到前方，再在滑翔途中留出一段安静让桥显形。高处跨断桥，低处沿回声水面，看得清却多绕一个弯。

### 第三关 · 星海回响

1. **有限授权的领航星。** 玩家可跟随一束建议星光滑行两秒，在岔路前随时转到另一条道，或短暂握拳收回引导。可靠星光会给前方障碍留足距离，犹豫的星光会摇摆，复用玩家在森林学会的红色双闪。保留玩家主动接管的位置，最后星图能显示为什么在那里转向。
2. **接住一条真实的旧路线。** 星海的三个发光节点来自森林三次种光。遗迹留下的节拍决定各节点哪一个先亮。玩家从不同路线往返连结，选择急转近路或借顺风绕行。完成后，背景中的星线和人物窗里的指尖按同一节拍亮起，投影错开一点时也能看出因果。
3. **星浪接力。** 近处星浪有缓慢的低色带和短促的高色带。轻声贴着缓浪飞能延长顺风段。短声加速穿越高浪后要留出安静，让下一颗星复位。最后一轮让玩家自行选择是否等待系统的预测灯，个人星图留下已确认的路线和亲自改过的节点。

## 早期方案留档

把三章连成「留下什么、交给谁、世界怎么回答」。观众的动作要在场景里留下能辨认的结果，并进入下一幕。左侧暖光触点 A 表示「留在我身边」，右侧冷光触点 B 表示「交给世界」。玩家用同一只手依次摸两块，另一只手可以留在摄像头前。每段演出保留一次参与机会，也可以等它自行结束。

## 演出怎样接进游戏


1. **动作跨屏。** 精灵在人物窗拉出一段细光，手腕停住的同一刻，背景才长出花缘、门缝或星线。人物窗的高光集中在手，背景给更低的亮度和更松的边缘。让观众看清是精灵做了什么，世界才改变。
2. **把演出放在呼吸之间。** 通过一段高强度操作后，用 3–6 秒的点步或双人对舞让人从追目标切换成观察。期间只留一个简单动作，提示消失时平稳回到游戏。
3. **让上一段玩法决定演出动作。** 精灵先朝森林里玩家选中的第一处种光点伸手。遗迹里，由标记的时机决定谁先迈步。星海根据波强决定最后裙摆展开幅度。镜头和人物比例在演出进出时保持连续。
4. **用安静触发一段可选舞步。** 在遗迹中段的安全平台上，张手静候几秒，回声会从人物窗边缘探身模仿精灵的呼吸。玩家随时能用轻声继续前进。这段演出让已经熟悉操作的玩家有机会发现另一种节奏。

先在 Unity 做约 45–60 秒的森林试段。安排两个种光位置、有限的萤火和一次开花，验证画面变化是否足够让人理解 A/B 的区别。实现时先让键盘 A/B 和实体触点走同一事件，再增加长按或连续两次触摸。收敛后再做遗迹的短录制、星海的跨章回放。
