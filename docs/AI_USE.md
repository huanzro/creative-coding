- 用户要求对照《Echoes of Light · Unity 重开发技术选型》研究五类 GitHub 资源，并调整现有分镜、人物动作和萤火投影。库的取舍和关卡设计记在 [关卡设计与技术选型](UNITY_CHAPTER_PLAN.md)。
