# 《光的回响》设置详解

在主画面按 **F1**，或点设置按钮。英文模式使用同一组设置和同一份本机参数。先用键盘走完一小段，再开摄像头、麦克风或 Arduino，便于定位反应延迟来自输入还是画面。

## 语言、演出与输入

| 设置 | 用法 |
| --- | --- |
| 语言 / Language | 在 F1 主面板下方点击「English」或「中文」切换。组员排练时可切换语言查看玩法、角色提示和结尾页。 |
| 背景时段、背景速度 | 背景时段可选自动、薄暮、蓝调、月夜和破晓。背景速度范围 0.25–2.00 倍，用于预览背景运动，星海纵深由巡航速度单独控制。 |
| 预览片头 / Preview Prologue | 直接重放序幕。Esc 可跳过，正式体验从庭院进片头。 |
| 出场角色 / Cast | 在三维精灵、绿金长裙精灵、兜帽旅人、星纹术士、红色小鸟和黑天鹅中选择。人物窗和主画面用相同角色。鸟类用翼尖完成接触与作画。 |
| 摄像头 / Camera | 打开 **摄像头 / Arduino** 后启动摄像头，在本机识别页允许访问。识别到张手后，从浏览器切回游戏并保留本机识别页。镜头中要有整只手。星海只伸食指。 |
| 麦克风 / Microphone | 首次校准先安静约 2 秒，再舒适地哼声约 3 秒。音量控制游戏的前进强度。场地噪声变化后重新校准。 |
| Arduino | 在 Windows 检测到的端口中选正确的 COM 口并连接一次。重插后刷新端口。如果 COM 被占用，关闭 Arduino IDE 串口监视器。接收触点、双灯与风扇使用同一条 EOL3 串口。 |
| 模拟手离开画面、纯黑人物、镜像 | 无设备时可模拟识别丢失。单窗也能切成纯黑底人物并镜像，便于测试人物画面。 |
| 试玩使用三维背景 | 为庭院的单独排练切换三维显示。三关与序幕沿用各自的三维背景。 |

## 主画面与人物窗

打开 **F1 → 打开独立人物窗口**，把它移动到第二块显示器。Unity Editor 还能通过 **Echoes of Light → Character Projection** 打开。两个版本都可在人物窗按 **M** 切换镜像、**R** 切换直立与旋转方向。编辑器版另有 **H** 隐藏窗内控制条。Windows 玩家版可拖动窗口边缘调尺寸，按 Esc 关闭人物窗。单屏关闭人物窗后，角色回到游戏画面。

| 设置 | 范围 | 用途 |
| --- | --- | --- |
| 人物大小 | 35%–140% | 编辑器人物窗滑杆。适配副屏和反射面尺寸。人物接近边缘时会受窗口空间约束。 |
| 光效延展 | 0.65–2.45 倍 | 编辑器人物窗滑杆。在星海同时决定哪些笔迹交由独立人物窗显示。Windows 玩家版随人物窗尺寸和朝向重算覆盖范围。 |
| 启用人物周围渐亮 | 开 / 关 | 在人物后压暗背景，再向周围平滑恢复画面亮度。 |
| 全屏亮度 | 0.50–1.35，默认 1.00 | 调主画面整体明暗。 |
| 渐亮速率 | 0.25–4.00 | 最低档把中心背景压到纯黑。增大后暗区收得更紧。 |
| 背景、蜘蛛动画、食人花动画亮度 | 各 0–1.35，默认 1 | 分层控制主画面上的环境和两种森林捕获演出。0 隐藏相应层。 |
| 主画面大小 | 50%–100%，默认 100% | 等比缩放并留黑边。先用全幅对齐，确认光路后再缩。 |
| 结尾亮度 | 0.68–1.55 倍，默认 1.12 | 在星海的 F1 主面板调整最后金色画和片名收束的明亮程度。 |

星海校准时先开独立人物窗，再到 **F1 → 投影校准** 查看主画面覆盖边框。主画面保留框外笔迹与原有的背景和花萤。人物窗接手框内笔迹。由于反射面大小、角度和投影机位置都由布展决定，请以现场可见的边界为准。

## 操作强度

| 设置 | 范围与默认值 | 改动在什么时候生效 |
| --- | --- | --- |
| 左右移速 | 0.35–1.45 倍，默认 0.70 | 森林普通线路的 A/B 横移。 |
| 迷宫行走速度 | 0.65–2.00 倍，默认 1.30 | 三层迷宫前进速度。按住 A/B 仍按朝向转动。 |
| 蛛网、食人花捕捉范围 | 分别 0.45–1.65 倍，默认各 1.00 | 两种陷阱的命中范围。 |
| 萤火接触范围 | 0.50–2.00 倍，默认 1.00 | 红萤与黄萤共用。 |
| 常规单跳高度 | 0.50–2.00 倍，默认 1.00 | 下一次握拳后张手时生效。 |
| 右路门前单跳高度 | 0.75–4.00 倍，默认 2.60 | 右路机器门廊的单跳。 |
| 遗迹入口范围 | 四个方向各 0.65–1.65 倍，默认 1.00 | 分别决定按 A 向左、按 B 向右、上升、下降的接入距离。 |
| 星海巡航速度 | 0.25–1.65 米/秒，默认 0.72 | 无声巡航的基础速度。音量另加速。尾声距离固定为 94.5 米。 |

## 双灯与结尾图片

| 屏幕事件 | 实体灯 |
| --- | --- |
| 遗迹拾取物品 | 黄灯短闪。 |
| 结算交出心脏、大脑 | 红灯短闪。 |
| 星海按 A | A 侧灯短闪紫色。 |
| 星海按 B | B 侧灯短闪黄色。 |
| 星海尾声 | 两侧亮黄灯同闪，随后渐变为白灯。 |

Arduino 有灯光和风扇独立开关。启用风扇前先确认组合固件支持。失焦、暂停、关闭或串口失联时应清空实体输出。展台验证单侧灯色、结束渐变和熄灯时分别记录回执与现场观察，不以屏幕显示替代实体效果。[接线与串口](EXHIBIT_WIRING.md)

结尾后，Windows 版会把金色 PNG 保存到游戏本机数据的 `Star Sea keepsakes` 目录。通过尾声的「打开保存位置」可找到文件。让手机与展台电脑连接同一可互通的网络，再扫描尾声中的二维码。若场地网络启用了客户端隔离，可用本机保存的图转交。二维码提供当次作品的网络地址，画面关闭后请使用本地文件。
