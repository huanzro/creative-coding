# 音量与光迹调试

本版只识别音量大小，不识别音调。设计意图：轻声让世界缓缓掠过，较大的声音让旅程加速，留下更明显的光迹。人物仍在画面中心，手势 / 键盘继续负责跃起、聚光和共鸣。

## 使用

1. 运行 `python server.py --open`，在 Edge / Chrome 中打开 localhost 页面。
2. 点击“开启麦克风”，允许音频输入；默认请求关闭自动增益、降噪和回声消除，避免它们抹平音量差异。设备可能不完全支持这些约束，仍需现场校准。
3. 点击“校准环境噪声”，保持安静两秒。
4. 正常发声观察读数：安静时缓慢停下，大声时加速。这里的 dBFS 是麦克风数字信号相对满幅度，不是声压计测得的 dB SPL。
5. 手势或空格继续改变高度和释放能力。两种输入可以同时用；选择手势但摄像头未就绪 / 丢手时仍会暂停整个体验。
6. 开启双屏投影后，人物与增强光迹在纯黑人物窗口显示；背景端保持中央柔和暗区。

## 参数

| 参数 | 默认 | 作用 |
|---|---:|---|
| 安静阈值 | −48 dBFS | 低于它时目标速度为零；越高越不容易被背景噪声触发 |
| 满速阈值 | −18 dBFS | 达到它时接近最高速度；降低它更容易加速 |
| 最高速度 | 2.2× | 原始关卡速度的倍数；可调 0.5–3× |
| 加速平滑 | 0.18 s | 越小响应越快，越大越柔和 |
| 减速平滑 | 0.65 s | 安静后的滑行衰减时间常数，不是固定停止延时 |
| 光迹强度 | 1.5 | 控制光带与粒子亮度；可调 0.5–3 |

阈值之间至少保留 6 dB。校准采用两秒输入的 90 分位值加 6 dB，降低偶发单次峰值的影响。参数只保存在当前浏览器本机；“恢复默认参数”可清除调参影响。

关闭麦克风后恢复原有 1× 速度。拒绝权限 / 设备断连不会阻止键盘玩法。页面不录音、不播放麦克风，也不上传音频。

## 不接设备先调试

展开“声音与光迹调试”，勾选“模拟音量”。移动模拟 dBFS 滑块，在安静、轻声、较响之间观察速度、光带及风灯预览。模拟模式自动停止麦克风并取消硬件启用，不能让模拟信号驱动实物。

光迹由宽柔光、彩色光带、细亮芯和持续微粒组成。轨迹沿角色的实际世界路径移动，颜色与场景一致；提高音量增加能量，改变速度使光迹在空间中伸展。轨迹 60 Hz 采样、最多 450 点；粒子最多 200 颗。

核心逻辑见 `dist/volume-core.js`，麦克风生命周期见 `dist/audio-input.js`，控制面板与联动见 `dist/interaction-controls.js`。这些文件均不依赖音频识别云服务。
