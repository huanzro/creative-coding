# 《光的回响》｜机器如何听见我

玩家面对一位会回应、也会等候的灯光精灵。三章让玩家体验从**发现机器接收到什么**，到**纠正它替自己作出的推断**，再到**决定可以委托它什么**。角色在黑底投影上作出可读的身体反应，场景在另一块屏幕上显出反应带来的后果。观众会从两块屏幕之间的时间差看出什么是自己的动作，什么是系统的建议。

## 可试玩的动作语言

现有三章规则已经能串起来。新版为同一组输入制作随场景变化的动作。A/B 动画由现有键盘、界面按钮和实体触点共用的事件触发。发声使用当前已有的音量强度，展览版若再次引入琴弦，可用音高分辨方向，继续用强度控制手势幅度。

**琴弦音高的动作提案**　共用「高音抬升、低音落下」的动作方向。森林里高音踮脚托萤火穿过树冠，低音蹲下把光交给树根。遗迹里高音沿高处门印向上探，低音贴近低处石壁辨认回声。星海高音伸展成上扬的弧，低音屈膝向下划一圈收住波纹。琴弦还待接入，现有的 Z/X 对应音量强度。

三维角色采用有厚度的面部、花瓣和背部结构。关节、裙瓣和飘带按输入计算。主画面与人物窗共用带深度的角色渲染，主画面在分屏时继续显示较淡的余光。动作造型是这次原型的组成部分，下节的关卡机制和跨章结果是下一轮的设计。

## 三章的体验改造

### 一　沉睡森林 · 机器眼中的我

把新手教学安排在一小片暗林。观众张手看到精灵朝同侧展开，发声会看到光核强度改变。第一次刻意让手离开画面时，场景继续微微呼吸，精灵垂手等候。让观众发现「我停下了」和「系统看不见了」可以是两件不同的事。

沿路只发两次种光机会。触 A 护住现在这一束，触 B 在当前位置种下。第一朵花开时给一个三秒的中段演出。人物窗里，她放低身体、手离开花种后才站起。背景从种植点亮一小圈。这样能够比提示文字更直接地让人读懂两种触摸的后果。

### 二　回声之门 · 机器可以猜错

把现有节拍录制改成可以看见和修改的候选回放。遗迹会展示一段确定性的猜测，例如将两次短促握拳合并成一次长握。玩家先看到薄蓝残影试跳，摸 A 保留自己的原节拍，摸 B 授权使用残影的建议。两种选择都能过关，各自打开门的一侧，留下一种不同的节拍。

在门开启前留一拍空白。人物窗里两位精灵互伸手腕，近乎接触时由观众做最后一次触摸。若识别暂时丢失，残影停在姿势上等下一次明确输入。误读、参考回放和识别丢失用三种可辨认的动作说明，避免让人误以为是自己的操作失败。

### 三　星海回响 · 哪些事可以交给它

森林的选点成为星的位置，遗迹留下的节拍决定点亮顺序。玩家看见精灵试演下一小段航线，摸 A 只保存这次保留的节拍，摸 B 让精灵把这一段继续连完。被委托的光线稍淡，亲自选中的星点更暖。

结尾可用 5 秒让角色走过自己的星图。人物窗是转身和脚步，背景是由本次选择生成的线路。即使玩家把大部分路交给精灵，最后一颗星也等玩家亲自点亮。展台叙事用规则回放来表现选择权，现阶段系统实际识别的是手部姿态和发声强度。
