# 《光的回响》｜谁在引路

一束光能救精灵，也能把她带向错误的地方。玩家从身体发出的手势、声音和触摸开始，逐渐学会观察反馈，保留自己的节拍，决定什么时候可以借用系统的帮助。

## 参考如何进入作品

Awwwards 收录页展示 Focus Industries 的片头、三维飞行、主页滚动和分段过渡。我们从中提取了两个做法。让人的视线跟着同一个运动主体跨过段落，用镜头速度和空间尺度交代变化。在《光的回响》里，黄萤火承担这条视线，三处空间分别用草叶、石壁和远空的光接续它的运动。 [Awwwards 案例](https://www.awwwards.com/sites/focus-industries)

Focus Industries 的原站把任务由人设定、自主系统执行路线的关系摆到前面。本作把选择放在人能看见的时刻。玩家先看见光是怎样回应的，再决定跟随、绕开、保留原节拍或借用一小步协助。 [Focus Industries 原站](https://www.focusindustries.tech/) · [Google PAIR 的反馈与控制](https://pair.withgoogle.com/guidebook-v2/chapter/feedback-controls/)

## 试玩场景与正片的关系

启动先进入**回声庭院**。第一次练习先张手，再握拳约半秒并松开，观察光圈怎样把精灵托起，以及她如何收慢速度回落。第二次先在张手时轻声，再握拳发声并维持声音张手，看见加速时更长的光迹与立体转身。完成后可以继续练习，触摸 A 或 B 才开始序幕。

全程动线为 **回声庭院 → 序幕 → 沉睡森林 → 回声之门 → 星海回响**。底部四个场景入口供组员单独排练。Unity Play Mode 中可用 **F1 → 预览片头** 或编辑器菜单单独回看序幕。序幕约 38 秒，结尾接第一关，**Esc** 可以提前进入同一落点。

## 序幕分镜

| 时段 | 表演与景别 | 接到下一个镜头的动作 |
| --- | --- | --- |
| 0–7.4 秒 · 林下 | 贴地向前。精灵拨开草叶，在潮湿树根旁倾身，向黄萤火伸手。镜头缩短与手的距离，虫翼和光稍慢半拍。 | 精灵还没有真正触到虫，脚底突然失去支撑。树根与阴影由下往上掠过画面。 |
| 7.4–15.6 秒 · 遗迹 | 视野放宽，石拱与吊根侧过。精灵失衡、转肩、收腿。黄萤火从上方出现，暖光带接到手边，她抬手抓住这条光，坠势反过来。 | 跟着正在上升的黄光越过石缝，洞口和森林的暖空气接在一起。 |
| 15.6–23 秒 · 越过树冠 | 回到森林，黄萤火渐渐合为光点，沿上方消失。精灵先抬头，再用身体追上；近景变成树冠剪影。 | 树冠沿原来的上升方向沉到画面下缘，星光补进暗处。 |
| 23–31.4 秒 · 星海与红光 | 精灵停一下观察红萤火，再抬手轻触。红光贴近指尖后绕住肩和裙，身体失去重心，被带向下方。 | 红色余迹先掠入树冠，森林地面接住同一股下降动势。 |
| 31.4–37.6 秒 · 回到地面 | 收膝翻滚，伸手撑一下地，尘屑散开。精灵慢慢坐直，抬手揉头，重心回到脚下。 | 接住序幕最后一个林下构图和精灵落点。第一关提示渐入，背景开始滚动。 |

青绿湿雾贯穿森林和遗迹，黄光始终柔和，红光只在精灵近身时扩散。序幕使用三张专用环境底图、实时三维角色、环境染色、前景草叶和程序配乐。镜头由路径曲线推动，手与萤火接触位置从同一角色姿态计算。

## 三个关卡体验

| 章节 | 体验 | A / B 的可试玩含义 |
| --- | --- | --- |
| **沉睡森林 · 人类曲折前进的赞歌** | 护送萤火跨过断路。拾起的黄光留下位置记忆，林荫路线让探索更稳，风带路线更短，遇到扰动时需要护光。红光靠近会明显闪动，碰到会打断上升，滑远后可以继续。 | 正常飞行时 **A 看轨迹**，短时间标出萤火接近的路线。**B 借一步**，给一个有间隔的小幅上托。分岔时，A 选林荫，B 选风带。 |
| **回声之门 · 人机交互的困境** | 遗迹只能记住部分动作。残影和玩家的当前动作同时存在，玩家可以按自己的记录重做，也可以让机器出的补位节拍加入。配合失败保留原记录。 | **A 按自己的节拍**，**B 借用互补的回声**。两种都可以开门，玩家保有重试和换法的机会。 |
| **星海回响 · 人机交互的希望** | 用同相和反相让来波相遇，找到能照亮或平息场景的组合。途中收集的黄光决定尾声的星点位置。最后可以自己触亮一颗星，或张开手等波纹在远处回稳。 | A/B 切换同相和反相。尾声允许 **A 点最后一颗星**。这个触点让玩家亲自决定何时结束演出。 |

三章每次只让一只黄或红萤火接近，上一只离开后再随机等几秒。黄光慢振翅，靠近时张手配合轻声更容易引到身旁。红光有急促脉冲和短环，能用高度差躲开。萤火收集记录来自当次旅程，结尾会把这些位置接成星图。

## 图像来源与生成要求

环境底图由内置 ImageGen 生成，存储在 Unity 的 [Opening 素材目录](../unity/Assets/Resources/Opening)。生成提示归纳如下。

- **Forest.png**　16:9 林下低机位，蓝调时分的老树林，湿草、盘根、薄雾与右上方蜂蜜色天光，底部留下扎实的草根与小地洞。中部留给后合成角色，无人物、飞虫和文字。
- **Ruins.png**　16:9 地下旧石拱与纵深竖井，前景吊根，顶部小开口洒入冷光，中段留出坠落空间。无人物、光点和文字。
- **Stars.png**　16:9 高于树冠的靛蓝空域，底部远林与薄雾，暗色空中保留细小远星与淡淡的银色弧带。无主光点、人物和文字。
